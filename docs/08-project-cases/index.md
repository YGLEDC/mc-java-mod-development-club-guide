# Project Cases

This directory will preserve valuable development cases from collaborative club
projects.

## Official Mod Projects

The club officer board may publish one official project each semester. A second
project may be offered when time and circumstances allow.

Members who have developed the required skills will be able to apply to
participate. The project's development process can later be documented here as
a learning case.

## Member-Led Mod Projects

Members who demonstrate the required development skills may qualify as Project
Leaders. A Project Leader can propose a mod, invite other qualified members,
and organize a project group.

Project groups may document their development process and submit it to the
officer board for possible inclusion in this directory.
