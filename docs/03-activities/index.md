# Activities

Activities are the main hands-on learning part of the guide. Each activity
helps you learn some Minecraft development components with real progress!

At most times, each future activity is based on its previous one. In other words, for example, Act 2 would be based on Act 1, following this sequential order.

It is highligh recommended to make a backup and keep track of your work, and one way to do that is through GitHub. See [GitHub & Version Control](../01-introduction/04-github-version-control.md) for more information on how to do this.

New activities would be added as the club advances.

Feel free to join our Club Activity Party and learn together! 
> See Google Classroom for more info.
